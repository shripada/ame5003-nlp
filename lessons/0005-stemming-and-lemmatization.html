Stemming and lemmatization

Reducing a word to a root form by two different methods, and deciding which one a given task requires.

Where session 4 left off

In session 4 we collapsed differences of case, accent, and punctuation. One further difference remains, and it is the largest: the same word appears with different endings.

study    studies    studying    studied

These are four inflected forms of a single word. For counting and for search we usually want them to count as the same item, so that a user searching for studying finds a page containing studies. We therefore reduce each word to a shared root.

There are two methods for doing this. This session covers how they differ and when each is appropriate.

Stemming

Stemming removes recognisable endings from a word using a fixed set of rules. The standard tool is the Porter stemmer, which applies an ordered list of rules of the form "if a word ends in -ing, remove it".

Applying it to the study family produces the same string in every case:

study      →  studi
studies    →  studi
studying   →  studi
studied    →  studi

Note that studi is not a word of English. This is not a defect. The stemmer has a single objective, which is to map related words to the same string, and it achieves that. studi is never displayed; it serves only as an internal key. For search this is sufficient, since all four forms now match one another.

A second family collapses in the same way:

argue  argued  argues  arguing    →    all become  argu

The limitations of rule-based stemming

Because the stemmer applies rules without any representation of meaning, it makes errors:

organization   →  organ      (the meaning is lost)
was            →  wa         (not a word)
mice           →  mice       (unchanged — see below)
better         →  better     (no relation to "good" is recognised)
  • organization → organ: the rule removed too much and changed the meaning. This is called over-stemming.
  • was → wa: a rule applied that should not have, leaving a non-word.
  • mice → mice: the stemmer can only remove endings. An irregular plural such as mice has no ending to remove, so the stemmer cannot reach mouse.

Stemming is fast and requires no dictionary, and for search it is often adequate. It produces non-words, however, and handles irregular forms poorly. When the root must itself be a word, we need the second method.

Lemmatization

Lemmatization also reduces a word to a root, but the root is a dictionary form, called the lemma. Rather than removing endings, it looks the word up, which allows it to handle the cases stemming cannot:

mice     →  mouse       (irregular plural — correct)
was      →  be          (irregular verb — correct)
better   →  good        (knows the words are related)
studies  →  study       (a real word, not "studi")

Every output is a word that appears in a dictionary. This is the essential difference between the two methods: a stem is a shared key, whereas a lemma is the base form of the word.

Lemmatization requires the part of speech

There is a complication, and it is the reason lemmatization is harder than it first appears. The root of a word can depend on how the word is used in the sentence. Consider meeting:

"we had a meeting"       meeting is a NOUN  →  lemma is  meeting
"they are meeting now"   meeting is a VERB  →  lemma is  meet

The spelling is identical and the roots differ. The only thing distinguishing them is the part of speech: whether meeting is a noun or a verb in this sentence. A lemmatizer that is not given the part of speech must guess, and it generally guesses "noun". When that guess is wrong, the result is wrong:

lemmatize("was")            →  wa      (guessed noun — wrong, and no better than stemming)
lemmatize("was", verb)      →  be      (told it is a verb — correct)

lemmatize("better")         →  better  (guessed noun — wrong)
lemmatize("better", adj)    →  good    (told it is an adjective — correct)

Lemmatization is therefore only as accurate as the part-of-speech information supplied to it, and labelling every word by hand is not practical. A tool such as spaCy determines the part of speech automatically and lemmatizes in a single step, which is why it is the usual choice in practice. Determining the part of speech is itself a substantial task, and it is the subject of session 6.

Exercise

Suppose we are building a search engine over several million documents. It must be fast, and the roots are never shown to a user; they are used only to match a query against a document. Should we stem or lemmatize?

Stem. Speed matters, the roots are never displayed, and non-words such as studi are acceptable because they serve only as internal match keys. A dictionary lookup for every word would be slower and would provide no benefit here.

If the task changes so that root words are shown to a user, or supplied as input to a model, the answer becomes lemmatize, since studi and wa would then be visible. As in session 4, the correct choice depends on the task.

Question 1 of 2

The Porter stemmer turns organization into organ. Why is this not necessarily a problem?

Correct answer: for search, all that matters is that related words share a key.

A stem is only an internal match key and is never displayed. If organization and organizations both become organ, a search for either finds the other, which is the goal. It does become a genuine problem when organ, meaning the instrument or the body part, also stems to organ and is matched incorrectly. This over-collapsing is the cost of the rule-based approach. For a task that depends on meaning, use a lemma.

Question 2 of 2

Why can a lemmatizer turn was into be, when the Porter stemmer only manages wa?

Correct answer: the lemmatizer looks the word up, so it knows irregular forms.

Stemming only removes endings, so an irregular form such as was → be or mice → mouse is beyond its reach, since there is no ending to remove. Lemmatization uses a dictionary of forms and can therefore map any inflected form to its base word. The costs are that it requires the part of speech and that it is slower.

Summary

The main points

Stemming removes endings by rule. It is fast, requires no dictionary, need not produce a real word, and is the appropriate tool for search. Lemmatization looks up the dictionary root. It is accurate, requires the part of speech, is slower, and is the appropriate tool when the output must consist of real words.

This completes the text-cleaning sequence: tokenization, normalization and stop-word removal, and reduction to a root. Session 6 begins working with the cleaned words, starting with part-of-speech tagging, which is the information lemmatization required.
